## ⭐ Featured Projects
### ⚙️ [Alloy](https://github.com/AlloyForge/alloy) — a programming language in C
A handwritten interpreted language built from the ground up: lexer, recursive-descent parser with Pratt-style expression parsing, AST, and tree-walking evaluator, all in C with no parser generators.
Supports typed variables, operator precedence, int→float promotion, `if / elif / else`, `while` loops, and typed functions with return values.
`C` `Interpreters` `Language Design`

### 🎵 [Music Sync](https://github.com/josh-keilder/music-sync) — Android music library sync
A native Android app (Kotlin + Jetpack Compose) that compares songs on my phone with a Google Drive folder and downloads or uploads whatever is missing, with progress tracking.
Built with Google Sign-In, the Drive REST API via Retrofit, MVVM with ViewModels, and a feature-based package structure.
`Kotlin` `Jetpack Compose` `Google Drive API` `Retrofit`

### 📚 [SkillSwap](https://github.com/josh-keilder/SkillSwap) — peer-to-peer learning platform
A full-stack Django web app where users teach and learn skills. Teachers set weekly availability, learners book open time slots or enroll right away in self-paced courses, and each role has its own dashboard.
`Python` `Django` `SQLite` `Full-Stack`

### 🎮 [Dungeon Sprint](https://github.com/josh-keilder/dungeon-sprint) — 2D dungeon crawler
A top-down action game in Pygame with a state machine for menus and gameplay, a camera that follows the player, an inventory with equipment slots, enemies with health bars, and levels loaded from Tiled (TMX) maps.
`Python` `Pygame` `Game Dev`
